## Anatomy

Icon is a square whose width and height come from `size/icon/*`. It nests one instance of the glyph set **Lucide icons** (layer `Glyph`), which fills it.

- Stroke colour is an `icon/*` token.
- Stroke weight is size ÷ 24 (sm 0.667 px, md 0.833 px, lg 1 px), so every size looks like a scaled 24 px Lucide glyph. This is a derived value, not a token.
- The glyph is swapped through the property `icon`.

"Lucide icons" is described in Figma as the only allowed source of icons on screens.

## Sizes

| size | Pixels | Token | Used for |
| --- | --- | --- | --- |
| `sm` | 16 | `size/icon/sm` | metric tiles, card buttons, chevrons, pagination, theme toggle, clock, AI-input toolbar and send |
| `md` | 20 | `size/icon/md` | sidebar items, header buttons, selector chevrons |
| `lg` | 24 | `size/icon/lg` | panel-right in the logo, hidden Wallet field |

16 px is the smallest icon size (decided by Mary).

## Colours

The seven original colours are documented with their use. The five status colours were added later (changelog) without usage notes.

| color | Token | Used for |
| --- | --- | --- |
| `default` | `icon/default` | metric tiles, theme toggle |
| `muted` | `icon/muted` | selector chevrons, credit-card and arrow in cards, glass button |
| `strong` | `icon/strong` | AI chat controls (send, paperclip, mic) |
| `primary` | `icon/primary` | card notch chevrons |
| `accent` | `icon/accent` | Buy euro plus |
| `inverse` | `icon/inverse` | Issue card plus, selected Menu Item |
| `inverse-muted` | `icon/inverse-muted` | default Menu Item on the dark sidebar |
| `positive`, `warning`, `danger`, `info`, `success` | `icon/positive` … `icon/success` | <NotDocumented /> |

**Rules:** `inverse` and `inverse-muted` are for dark surfaces only. The `google` and `apple` variants are brand marks: the colour property does not recolour them. External images (coins, logo, avatar) are not Icon instances.

## Implementation

<StatusBadge status="Portal implementation" /> No production package exists. This is the API of the preview library in this portal, pending developer validation.

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `name` | glyph name | required | Figma `icon` (instance swap). All 101 variants are available. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'sm'` | Figma `size`. |
| `color` | one of the 12 colours | inherits | Figma `color`. |

97 glyphs render from the open-source Lucide package; `google`, `apple`, `star-filled` and `cursor` are not in it, so their vectors were exported from Figma.

## Accessibility

From Figma: icons are decorative by default. An icon-only control must get its accessible name from the parent (Button, IconButton). Meaning must not rely on colour alone. All colours pass 3:1 against their intended surface. "Keyboard and screen-reader behaviour need implementation validation."

In the portal the icon is rendered with `aria-hidden`.

## Edge cases and decisions

| Status in Figma | Finding |
| --- | --- |
| Decided by Mary | Thin line kept: stroke weight = size ÷ 24. |
| Decided by Mary | 16 px is the smallest icon size. On the copy screen: clock 12 → 16, sun 14 → 16, send 15 → 16, paperclip and mic 14 → 16. |
| Fixed | Contrast: `icon/muted` was #a098aa (about 2.8:1 on white). It is now #8d8696: 3.5:1 on white and 3.2:1 on `surface/muted`. |
| Not added | An image icon: the source was hidden and its vector incomplete. |
