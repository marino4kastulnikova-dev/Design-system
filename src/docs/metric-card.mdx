## Composition

Organism. A single component with the text properties `title` and `value` and the boolean `showDelta`.

| Nested component | Instances | Note |
| --- | --- | --- |
| IconTile | 1 | Left |
| StatusBadge | 1 | Right, optional (layer "Delta") |

Evidence in Figma: 4 cards on the dashboard (Team members, API Calls Today, Success rate API, Volume Today).

## Usage

A row of four cards, each set to fill. The icon glyph and the delta badge are changed on the nested instances (Icon, Delta).

## Accessibility

From Figma: each card is a group with title and value; the delta needs text like "up 18%" for screen readers. The portal renders the card as a labelled group and adds a visually hidden "up" or "down" to the delta.

## Edge cases and decisions

| Status in Figma | Finding |
| --- | --- |
| Observed | The four source cards had three different inner structures (card 4 was flat, cards 1–3 nested; gap 10 vs 12). One structure now, gap 12. |

| APPROVED | Card fill = `alpha/white-20` (new semantic `surface/card`) + effect `glass/default`. |
