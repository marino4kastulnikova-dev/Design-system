## Composition

A single component built from plain frames and text: a label on the left and a value on the right, space-between.

## Usage

Inside the detail card of a modal: Merchant, Card, Verification, Converted, Rate, Fees. Evidence: 6 rows in the Confirm payment and Convert success modals.

## Accessibility

From Figma: use a description list (`dt` / `dd`). The portal renders each row as a `dt` / `dd` pair; place the rows inside a `dl`.
