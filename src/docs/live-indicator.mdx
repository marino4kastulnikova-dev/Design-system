## Composition

A single component: a 16 px clock icon and caption text, with a 6 px gap. It has no component properties: the text is edited directly in the instance.

It nests a component named `icon-clock`, not the Icon component.

## Usage

Page header, next to the theme toggle. Evidence: one occurrence on the dashboard.
