## Composition

Organism. A single component: the Convert form (From / To boxes, exchange arrow) on the left and the summary panel with the exchange rate and the action on the right.

| Nested component | Instances | Note |
| --- | --- | --- |
| icon-transactions | 2 | Coin icons, external library instances |
| Lucide icons | 3 | |
| IconButton | 1 | Exchange arrow |
| Divider | 1 | Rate block |
| Button | 1 | Confirm |

Evidence in Figma: the dashboard; the same widget opens the wallet dropdowns and drives the Convert modals.

## Behaviour

Figma describes this page as a purely visual composition: behaviour and data come from the implementation. What the portal does, all <Proposed />:

- Each currency selector opens a DropdownPanel under it (`kind` from / to); choosing a row closes it. Escape and a click outside close it too.
- The exchange button swaps From and To and shows a "Swap" Tooltip.
- Amounts and the rate are display strings supplied by the caller; the widget does no arithmetic.

## Usage

Right of the account cards. The currency selectors (USDT / USDC) and the amount displays are frames here, not molecules yet.

## Implementation

<StatusBadge status="Portal implementation" /> No production package exists. This is the API of the preview library in this portal, pending developer validation.

| Prop | Type | Notes |
| --- | --- | --- |
| `onContinue` | `() => void` | The Figma developer mapping names the callback `onConfirm`; the drawn button label is used for the name here. <Proposed /> Align the name. |
| `wallets`, `external` | `Wallet[]`, `ExternalDestination[]` | <Proposed /> Rows of the two dropdowns. |
| `from`, `to`, `onChange` | `string`, `string`, `(next) => void` | <Proposed /> Selected wallet ids. |
| `amount`, `fiat`, `receive`, `rate`, `note` | `string` | <Proposed /> Display strings. |

TokenSelect is internal to the widget in the portal, because Figma has not extracted it as a component.

## Accessibility

From Figma: form controls need labels ("From", "To"); the exchange button needs `aria-label` "Swap". The portal names each selector "From: (wallet)" / "To: (wallet)" with `aria-haspopup="listbox"` and `aria-expanded`, and names the exchange button "Swap".
