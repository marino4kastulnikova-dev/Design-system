## Composition

From the component description: the confirmation step before moving money between or out of the merchant's accounts.

| `type` | Meaning |
| --- | --- |
| `conversion` | Exchange between currencies. The rate is locked and the timer shows for how long. `state = expired`: the rate is stale and the primary action is Update rate. |
| `transfer` | Same-currency transfer between own wallets. No rate and no timer. |
| `withdrawal` | Crypto to an external address. The full address is shown for checking; network and network fee are visible. |

No 3-D Secure: that applies only to card purchases and stays in the bot.

Four variants are drawn: conversion / active, conversion / expired, transfer / active, withdrawal / active. Expired transfer and withdrawal do not exist.

Nested in the live component: StatusBadge (timer, conversion only), Divider, DetailRow, Button ×2. The IconButton and MessageBanner named in the documentation are not present.

## Usage

Shown over the dashboard behind a scrim (`surface/scrim`), inside ModalOverlay. Text values are edited on the nested instances.

## Accessibility

From Figma: `role="dialog"` with `aria-modal`, focus trapped, Escape closes; the countdown needs a live announcement. The dialog behaviour comes from ModalOverlay. The timer badge is a `role="status"` region, so a changed label is announced.
