## Anatomy

A single-line field on a translucent white surface. A select trigger is the same field with a trailing chevron.

- **LeadingIcon** — Icon lg 24, muted; optional through `showLeadingIcon`.
- **Value** — `typography/body-sm`; placeholder in `text/muted`, value in `text/primary`. It truncates.
- **TrailingIcon** — Icon lg 24, muted; optional through `showTrailingIcon`. `chevron-down` for a select.

One height: 40 px (`size/control/md`). The component is 240 px wide by default; in the product the search field is 290 and the selects are 182.

## States

Only default is observed; the others were approved by Mary on 2026-09-21. Read-only was approved on 2026-09-25.

| State | Treatment |
| --- | --- |
| Default | fill `surface/field`, 1 px inside outline `border/hairline` |
| Hover | fill `surface/field-hover` |
| Focus | outline `border/focus` |
| Error | outline `status/danger-text` |
| Disabled | `opacity/disabled` (40%) |
| Read-only | value only: no leading icon, trailing `copy` icon |

## Usage

| Users — All Statuses / All KYC | trailing `chevron-down`, no leading icon, width 182 |
| Account details modal | read-only, trailing `copy` |

The Filter button next to the search is an icon-only Button, not part of Input.

## Accessibility

- Placeholder `text/muted` on white 60% is about 4:1.
- Keyboard behaviour of the select (listbox) needs implementation validation.

Verified gap: an error message element is not designed.
