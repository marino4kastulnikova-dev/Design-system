## Anatomy

A pill 18 px high with a minimum width of 18 px: padding 0 / 6, radius full, fill `brand`, and a centred count in `typography/caption-strong` and `text/inverse`.

The Button variants contain a hidden layer named `Count` of the same size (18 × 18), which suggests the badge is meant to sit inside a button. That use is not documented.
