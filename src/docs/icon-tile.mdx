## Anatomy

A round, static tile with an Icon instance inside. It is not a button: the metric tiles were named button_48px in the source but are not interactive.

- Square, `size/tile/md` (32) or `size/tile/lg` (64), radius full, fill by appearance.
- The Icon colour follows the appearance; the glyph is swappable through the exposed property.

## Variants

| Variant | Used for | Default glyph |
| --- | --- | --- |
| neutral · md | Metric cards (Team members, API calls, Success rate, Volume) | `users` |
| positive · lg | Convert modal — Success | `check` |
| danger · lg | Convert modal — Failed | `x` |
| neutral · lg | Not observed in the product | `users` |

No states: not interactive.

## Accessibility

From Figma: decorative by default; the text next to it carries the meaning. In the modals the status must also be written in text ("Converted 9,166.08 USDC", "Conversion failed"): colour and icon alone are not enough. The portal renders the tile with `aria-hidden`.
