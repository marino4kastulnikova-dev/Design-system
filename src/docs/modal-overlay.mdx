## Composition

Organism. A single component: a scrim (`surface/scrim`) and one modal slot.

| Nested component | Instances | Note |
| --- | --- | --- |
| ConfirmPaymentModal / ConvertModal | 1 | Instance-swap property `modal`; default ConfirmPaymentModal `state = active`. |

Evidence in Figma: the Confirm payment and Convert result modals sit on a 55% black scrim over the dashboard.

<Callout title="Documentation and component differ" kind="warning">
The documentation frame says the modal is placed 228 px from the top. The component description, updated 2026-10-02, says the opposite: the modal is centred in the overlay both ways (auto layout, centre / centre, no manual top offset), and must not be positioned with top padding. The portal follows the newer description and centres the modal.
</Callout>

## Usage

Put it as the last layer of a screen frame (absolute position, x = 0, y = 0) over the dashboard; switch the modal with the `modal` property.

## Accessibility

From Figma: modal semantics (`role="dialog"`, `aria-modal`, focus trap, scrim click) are implementation decisions. The portal's decisions, all <Proposed />:

- `role="dialog"` with `aria-modal="true"`, labelled by the modal title.
- Focus moves to the first focusable control on open, Tab cycles inside the dialog, and focus returns to the opener on close.
- Escape and a press on the scrim close the dialog.
