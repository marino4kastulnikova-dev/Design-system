## Composition

From the component description: the result of a money movement, shown after the confirmation modal. `type` conversion / transfer / withdrawal × `state` processing / success / failed.

- Processing blocks repeated submission.
- Failed always states that the balance has not changed.
- Withdrawal success shows the full address and the transaction hash with copy.

Nested: Spinner (processing), IconTile lg with Icon check or x (success, failed), DetailRow, Button. The documentation frame also lists an IconButton.

## Usage

Shown over the dashboard behind a scrim after pressing Confirm in the Convert widget, inside ModalOverlay.

The Spinner rotates in the portal; in Figma it is a static frame. <Proposed /> The rotation stops when reduced motion is requested.

## Accessibility

From Figma: processing needs `aria-busy` and `role="status"`; success and failure must be announced. In the portal the Spinner carries the processing label as a status, and the success and failure headings are `role="status"` regions.

Verified gap: `aria-busy` is not set, because the portal has no surrounding region that is being updated.
