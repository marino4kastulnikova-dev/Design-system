## Anatomy

One row of the sidebar navigation (a molecule: icon, label and an interactive surface).

- Root: horizontal auto-layout, width Fill (247 in the sidebar), height 48, padding 8 / 14, gap 12, `radius/md`.
- **Icon** — Icon instance, md 20; colour `inverse-muted`, `inverse` when active.
- **Label** — `typography/body-lg`, `text/inverse`.

White text on transparent: it looks empty on a light background.

## Usage

Sidebar: Home (selected), Users, Cards, PayIn/PayOut, Other transactions, IBAN, Wallets, Crypto, Fee plans, Tariff, Billing, Docs. API logs and Settings are hidden in the source.

The sidebar section titles ("Management", "Payments") are not part of this molecule: they stay in the Sidebar organism.

## Accessibility

From Figma: the selected item needs `aria-current="page"`. The white label on the dark sidebar has high contrast; the `inverse-muted` icon (#7e7887) on #19202e is about 3.8:1. The focus-visible ring is APPROVED.
