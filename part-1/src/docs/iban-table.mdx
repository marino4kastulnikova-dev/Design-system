## Composition

Organism. Two components: **IbanHeader** and **IbanRow** (state default / hover). Columns: Name (link), IBAN with a copy button, Owner, Currency, Balance, Status badge, Top up action.

Nested, as listed in Figma: Button (Top up), StatusBadge lg, IconButton tonal (copy).

Evidence in Figma: the IBAN screen, 2 rows; columns 200 / 280 / 320 / 64 / flex / 135 / 97, gap 40.

<Callout title="Documentation and component differ" kind="warning">
The documentation lists the copy button as IconButton tonal. In the live component it is IconButton ghost. The portal follows the live component.
</Callout>

## States

| IbanRow state | Difference | Source status |
| --- | --- | --- |
| `default` | No copy button | |
| `hover` | The copy button appears next to the IBAN | PROPOSED in Figma, from Mary's note of 2026-09-25 |

In the portal the copy button also appears when focus is inside the row, so that it can be reached from the keyboard. <Proposed />

Inside the IBAN screen panel: IbanHeader, then IbanRows, with Pagination below.

## Implementation

<StatusBadge status="Portal implementation" /> No production package exists. This is the API of the preview library in this portal, pending developer validation.

| Component | Prop | Type | Notes |
| --- | --- | --- | --- |
| IbanRow | `account` | `IbanAccount` | Holds `name`, `iban`, `owner`, `currency`, `balance` (Figma text properties) and `status`. One object instead of separate props is <Proposed />. |
| IbanRow | `onOpen` | `() => void` | From the Figma accessibility note: the name link opens the account details. |
| IbanRow | `onTopUp` | `() => void` | <Proposed /> |
| IbanHeader | none | | Fixed column labels, as drawn. |

The developer mapping in Figma lists only `message → message (string)`, which looks like a leftover from the MessageBanner page; it does not match the properties of IbanRow.

Copying: the portal writes the IBAN to the clipboard and swaps the icon to a check for a moment. The feedback is not designed in Figma. <Proposed />

## Accessibility

From Figma: table semantics (rows, columns); the name link opens the account details; the copy button needs an accessible name ("Copy IBAN"). The portal implements these, and names the Top up button after the account.
