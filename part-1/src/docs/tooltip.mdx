## Anatomy

A single component with one text property, `label`: a small raised bubble with padding 6 / 10, radius `radius/sm`, fill `surface/raised` and the effect `shadow/soft`. There is no arrow.

Evidence: a new component; the library had no tooltip. Its first use is the swap button in ConvertWidget.

## Usage

- Show on hover or keyboard focus of icon-only controls.
- Place it 8 px from the control, centred on it; flip to the other side when there is no room.
- One short line, sentence case, no full stop.
- Not for errors or information the user must read.

## Accessibility

From Figma: link to the control with `aria-describedby`. Show on keyboard focus as well as hover; dismiss with Esc. Do not put interactive content inside. The portal implements all three.
