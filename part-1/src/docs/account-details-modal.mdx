## Composition

Organism. A single component with the text properties `title`, `subtitle`, `amount` and `ibanLabel`; the nested instances are exposed. The IBAN sits in a read-only Input with a copy icon.

Nested, as listed in Figma: DetailRow ×3, Input (read-only), Button ×2, IconButton soft, Divider.

Evidence in Figma: the IBAN details screen "Personal account details". The original modal was a raw frame with a legacy Input Field. Copyable field: IBAN only (Mary, 2026-09-25).

## Usage

Place it inside ModalOverlay (slot "modal") on the IBAN details screen. Edit values on the exposed nested instances: IbanField, Row Owner / Currency / Status, Primary, Secondary.

## Accessibility

From Figma: `role="dialog"`; the copy control needs an accessible name ("Copy IBAN") and a live announcement. The portal provides both; the dialog role, focus trap and Escape come from ModalOverlay.
