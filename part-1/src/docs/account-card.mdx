## Composition

Organism. A component set with `appearance` iban / wallet. Text is edited on the instance.

| Nested component | Instances | Note |
| --- | --- | --- |
| ProgressBar | 1 | Transfer limit |
| Button | 2 | Linked card (inverse), Buy euro (tonal) |
| Lucide icons | 1 | |

Evidence in Figma: 2 cards on the dashboard, IBAN (25,567.40 EUR) and Wallet-1 (18,204.60 EUR).

<Callout title="Documentation and component differ" kind="warning">
The Figma documentation lists two actions (Linked card, Buy euro). In the live component the footer row of `appearance = iban` has 0% opacity, and no tonal "Buy euro" button is present in either variant: the wallet card shows the member photos and one Linked card button. The portal follows the live component.
</Callout>

## Usage

In the row with the Convert widget. The two appearances differ only by fill and decorative glows.

## Implementation

<StatusBadge status="Portal implementation" /> No production package exists. This is the API of the preview library in this portal, pending developer validation.

| Prop | Type | Notes |
| --- | --- | --- |
| `appearance` | `'iban' \| 'wallet'` | Figma `appearance`. The Figma developer mapping names this prop `type`. |
| `name`, `balance`, `currency`, `limit`, `spent` | `string` | <Proposed /> In Figma these are texts edited on the instance; the amount is one mixed-style text. |
| `progress` | `number` (0–100) | <Proposed /> Passed to ProgressBar. |
| `members`, `membersLabel` | `string[]`, `string` | <Proposed /> Wallet only. Each entry renders a neutral placeholder circle (max 3); the source uses photos, which the portal does not copy. |
| `onLinkedCard`, `onToggle` | `() => void` | <Proposed /> Linked card button and the notch. |

## Accessibility

From Figma: the card is a region labelled by the account name; the progress needs numbers. The portal labels the region with the name and passes limit and spent amounts to the progress bar.

Verified gap: the behaviour of the collapse notch is <NotDocumented />. In the portal it is a button that only calls `onToggle`.
