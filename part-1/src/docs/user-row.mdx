## Composition

Molecule. **UserRow** has 5 text properties and four exposed nested instances (Role, Status, KYC, Action). **UsersHeader** is its header row.

| Nested component | Instances | Note |
| --- | --- | --- |
| StatusBadge | 3 | Role tag, Status, KYC |
| Button | 1 | Cards action, size sm |

Evidence in Figma: the Users screen, 10 rows and 1 header.

<Callout title="Documentation and component differ" kind="warning">
The documentation says the Status and KYC badges are size lg (32 px, "decided by Mary"). In the live component they are size md. The portal follows the live component. <StatusBadge status="Proposed — needs review" /> Confirm which size is intended.
</Callout>

## Usage

Inside the Users table (screen "users (systemized copy)").

Hover, selected and empty states are <NotDocumented />.

## Accessibility

From Figma: table row semantics; the Cards button needs a name that includes the user. The portal names the button "Cards of (user name)".
