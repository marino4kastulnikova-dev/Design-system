## Anatomy

A square root with no fill (`size/spinner/*`) holding one ellipse, **Arc**: arc data start 0, end 4.5 rad, inner radius 0.82, filled with the paint style `gradient-spinner`. It scales with the root.

The arc is static in Figma. Rotation is called "an implementation detail" and motion is not designed.

## Accessibility

From Figma: needs `role="status"` or `aria-busy` and a text label. The rotation should respect `prefers-reduced-motion`. The portal sets `role="status"` with the label and honours reduced motion.
