## Composition

Organism. A component set with `kind` from / to. The From list holds wallets; the To list also has a group of external destinations.

| Nested component | Instances | Note |
| --- | --- | --- |
| WalletOption | 4 | |
| ExternalOption | in `kind = to` | Group of external destinations |

Evidence in Figma: originals 144:4728 (From) and 144:4758 (To).

## Selection

The component description in Figma is a note for the future, written in Russian. Translated: the selected row differs from the others only by its light-purple background (the check was removed so that the amount does not shift). For accessibility this is weak; if needed, strengthen it, for example with the weight of the title.

The portal does not add a second cue on its own. <Proposed /> Decide whether the selected title gets a heavier weight.

## Usage

Opens under the From or To selector of the Convert widget.

## Accessibility

From Figma: `role="listbox"` with `aria-selected` on the chosen option; keyboard arrows. The portal implements that, plus Home, End, Enter and Space. <Proposed />

Verified gap: the selected option is shown by background colour only (see Selection).
