## Composition

Organism. **Sidebar** is the full navigation column with logo, five sections and the profile footer. **SidebarCollapsed** is the icons-only version.

| Nested component | Instances | Note |
| --- | --- | --- |
| logo | 1 | External library instance |
| icon_32px | 1 | Sidebar toggle, external library instance |
| NavigationItem | 14 | 12 visible + 2 hidden rows |
| Divider | 1 | Footer line |
| Avatar | 1 | Profile |
| IconButton | 1 | Profile chevron |

Evidence in Figma: the dashboard (Home selected); the same sidebar appears on Users with Users selected.

## Collapsed

From the SidebarCollapsed description: icons only. The item name is shown in a Tooltip on hover or focus, to the right of the icon. The panel button at the top expands the menu. Group titles are hidden; groups keep their spacing. Status: DRAFT — pending Mary's approval.

SidebarCollapsed has no documentation frame. The transition between the two widths is <NotDocumented />; the portal switches without animation.

## Usage

Left of every dashboard-style page. The active page is set on the nested NavigationItem (`state = selected`); Home is selected on the dashboard.

## Accessibility

From Figma: landmark `nav` with `aria-label="Main"`; the active page has `aria-current="page"`. The portal implements both. In the collapsed version each item keeps its accessible name and shows it in a Tooltip on hover and focus.
