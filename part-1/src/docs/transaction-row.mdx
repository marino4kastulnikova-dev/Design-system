## Composition

Molecule. Three components: **TransactionRow** (7 text properties and a Status badge), **TransactionsHeader** and **Pagination**.

| Nested component | Instances | Note |
| --- | --- | --- |
| StatusBadge | 1 | Status (appearance and label per row) |
| IconButton | 2 | Pagination arrows |

Evidence in Figma: the dashboard has 6 rows, 1 header and 1 pagination bar.

## Layout

Column widths are set on the cells: 140 / fill / fill / 170 / 120 / 140 / 96 / 96 (date, user, type, merchant, card, amount, fee, status). There is no token for them.

Hover, selected and empty states of a row are <NotDocumented />. For a selectable row see transactions-grid.

## Usage

Inside TransactionsPanel.

## Implementation

<StatusBadge status="Portal implementation" /> No production package exists. This is the API of the preview library in this portal, pending developer validation.

| Component | Prop | Type | Notes |
| --- | --- | --- | --- |
| TransactionRow | `date`, `user`, `type`, `merchant`, `card`, `amount`, `fee` | `string` | Figma text properties, same names. |
| TransactionRow | `status` | `{ appearance, label }` | From the Figma developer mapping. |
| TransactionsHeader | none | | Fixed column labels, as drawn. |
| Pagination | `page`, `pages`, `onChange` | `number`, `number`, `(page) => void` | <Proposed /> Figma defines no properties for Pagination. |

The sample rows in the portal use synthetic names and merchants, not the texts of the Figma file.

## Accessibility

From Figma: use table row semantics. The portal renders rows with `role="row"` and cells with `role="cell"` / `role="columnheader"` inside a labelled table; the pagination arrows are named "Previous page" and "Next page" and are disabled at the ends. <Proposed />
