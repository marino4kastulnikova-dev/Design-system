## Anatomy

- **ProgressBar** — the track: width Fill, height 6, radius full, clips content, fill `alpha/white-12`.
- **Fill** — a frame with height 6, radius full and the paint style `gradient-progress`. Its width sets the value.

**Rule:** made for dark surfaces. The track is white at 12%.

## Value

Figma has no numeric component property: the value is the width of the Fill layer divided by the width of the track. Two values are observed: 44% (IBAN: 145 of 326) and 35% (Wallet-1: 113 of 326). In code the mapping says a number prop from 0 to 100.

No variants, no states: not interactive.

## Accessibility

From Figma: needs `role="progressbar"` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`, and the text value next to it ("Spent 4,450.00 EUR"). Colour is not the only carrier: the numbers are written. The portal sets the role and the three values.
