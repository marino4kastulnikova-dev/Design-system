## Composition

A single component: a two-segment toggle, 76 × 40, with a moon and a sun. The sun is the active thumb. It has no component properties.

It nests two raw glyphs from the Lucide set (`moon`, `sun`), not Icon instances.

<Callout title="Only one state is designed" kind="warning">
  Figma: "Dark theme is out of scope: the second state is not designed." A state property was not created. The system has one variable mode, so the toggle cannot switch anything.
</Callout>

## Usage

Page header, right side. Evidence: one occurrence on the dashboard.
