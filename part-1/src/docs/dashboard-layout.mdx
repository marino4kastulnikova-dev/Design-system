## Composition

Template. Sidebar on the left and a translucent Content panel with two dashed placeholder slots.

| Nested component | Instances | Note |
| --- | --- | --- |
| Sidebar | 1 | Left column |

Evidence in Figma: the dashboard, 1920 × 1080.

## Usage

Duplicate the frame structure for each dashboard-style screen; the placeholders show where PageHeader and the content blocks go. Figma cannot place children inside an instance slot, so screens are frames that mirror the template, not instances of it.

The second group under "Variants and states" assembles the dashboard from the components of this portal with synthetic data. It is an example, not a screen copied from Figma.

Responsive behaviour is <NotDocumented />: only the 1920 × 1080 desktop frame exists. The preview keeps the design width and scales it down to fit.
