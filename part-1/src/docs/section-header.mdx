## Composition

A molecule: the heading of a dashboard block with two actions. A Title text on the left and two exposed Button instances on the right (layers `Secondary action` and `Primary action`, size md).

Layout: horizontal, space-between, height 40, width Fill. The gap between the actions is `dimension/4`.

In Figma the note reads: "Added while rebuilding the dashboard strictly from components."

## Usage

Dashboard: the "Accounts" heading above the account cards, with Add user (secondary) and Issue card (primary).

Other screens with a heading and actions can reuse it. The Users heading has a subtitle and is not covered yet.
