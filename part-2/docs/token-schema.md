# Token export schema

Both exports are generated by `scripts/build-tokens.mjs` from `tokens/source/` and served at `/tokens/`.

## tokens.json

W3C Design Tokens community-group format. Top-level groups are the Figma collections
(`Colour Primitives`, `Colour Semantic`, `Dimension Primitives`, `Size Semantic`, `Border Width`, `Opacity`,
`Radius Primitives`, `Typography Primitives`) plus `Paint Styles`, `Effect Styles` and `Text Styles`.
A variable name such as `text/primary` becomes the path `Colour Semantic → text → primary`.

```json
{
  "Colour Semantic": {
    "text": {
      "primary": {
        "$type": "color",
        "$value": "{Colour Primitives.neutral.900}",
        "$extensions": {
          "com.figma": { "collection": "Colour Semantic", "variable": "text/primary", "kind": "semantic" },
          "baas.portal": { "cssVar": "--text-primary", "resolved": "#1c1229" }
        }
      }
    }
  }
}
```

| Field | Meaning |
| --- | --- |
| `$type` | `color`, `number` or `string` for variables; `gradient`, `shadow`, `typography` for styles. |
| `$value` | The value stored in Figma, or an alias reference `{Collection.path.to.token}`. Aliases are never flattened. |
| `$description` | The variable or style description from Figma, when present. |
| `$extensions["com.figma"]` | Exact Figma collection and variable (or style) name, and `primitive` / `semantic`. |
| `$extensions["baas.portal"]` | The CSS variable name and the final value after following aliases. |

Notes:

- Colours with alpha are written as `rgba(r, g, b, a)` so the Figma alpha is not rounded to 8-bit hex.
- Figma numbers are unitless and exported as `number`. `opacity/disabled` is `40` (a percent), as in Figma;
  the other opacity tokens are fractions.
- Style values are the raw Figma data (gradient transform matrices and stops; shadow layers with 0–1 sRGB colour).
- There is one mode. No mode dimension is encoded.

## tokens.css

`:root` custom properties. The name is the Figma name with `/` replaced by `-`: `surface/control` → `--surface-control`.

- Aliases stay aliases: `--surface-control: var(--neutral-200);`
- Dimension, size, radius, border-width, line-height and letter-spacing numbers get `px`. Opacity is unitless.
- Font weights `Regular`, `Medium`, `SemiBold` become `400`, `500`, `600`.
- Gradients are SVG data-URI images that stretch like a Figma paint. Use them as
  `background-image: var(--gradient-purple); background-size: 100% 100%;`
- Drop-shadow effect styles become `box-shadow` values (`--shadow-soft`). `glass/default` is a Figma glass effect
  with no CSS equivalent and is not exported to CSS.
- Text styles are classes: `typography/body-sm-strong` → `.ts-body-sm-strong`.
